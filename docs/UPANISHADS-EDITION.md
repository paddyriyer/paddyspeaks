# The Upaniṣads — the study editions (`/upanishads/`)

Read this before touching `upanishads/` or `scripts/upanishads/`. The brief that
every analysis record and study is written to is **`docs/UPANISHADS-BRIEF.md`**.

The collection began on 2026-11-01 with the **Īśāvāsya Upaniṣad** (Kāṇva
recension, 18 mantras). The second edition, the **Taittirīya Upaniṣad**
(Kṛṣṇa Yajurveda, Taittirīya Āraṇyaka 7–9: three vallīs, 31 anuvākas, 51
units), followed on 2026-11-02 — the whole text verified and collated, the
analysis published vallī by vallī (§ The Taittirīya). The order of work is the Rudram edition's: **verify the
Sanskrit first, explain it second, interpret it third, design it last.** The
architecture is built so the next Upaniṣad is a new folder of data, not a new
interface.

## Commands

```
python3 scripts/upanishads/check.py                  # the guardrail (Validate Content)
python3 scripts/upanishads/check.py --partial --mantra 4
node scripts/upanishads/build.mjs                    # regenerate the pages (also checks every internal link)
node scripts/upanishads/build.mjs --check            # CI: fail if a page is stale
node scripts/upanishads/render_test.mjs              # browser: pages, no-JS, paths, search (Accessibility workflow)
python3 scripts/platform_build/build.py all          # search index (core + verses shards), counts
python3 scripts/upanishads/import_witnesses.py --yajuh <vishvAsa/vedAH_yajuH> --raw <sanskrit/raw_etexts> [--ashta <sanskrit/ashtadhyayi>]
python3 scripts/upanishads/import_taittiriya.py --yajuh <vishvAsa/vedAH_yajuH> --raw <sanskrit/raw_etexts>
python3 scripts/upanishads/check.py --edition taittiriya --partial --mantra 1.11
```

## The sources (Īśāvāsya)

GitHub was the only source host reachable (sanskritdocuments, GRETIL, Wikisource
were refused), as for the Rudram and Devī Māhātmyam editions.

- **G (base)** — GRETIL Īśa-Upaniṣad, Kāṇva recension, in `sanskrit/raw_etexts`
  (`mixed/gretil_devanAgarI/…/isa-upanisad…md`). GRETIL states its mūla was checked
  against Limaye & Vadekar, *Eighteen Principal Upaniṣads* I (Poona 1958).
- **AS** — Advaita Sharada (Śṛṅgeri), mūla of Śaṅkara's bhāṣya (`raw_etexts`).
- **K** — Kāṇva Saṃhitā 40 with svara (`vishvAsa/vedAH_yajuH`). The only accented
  Kāṇva witness: shown on each page *as keyed*, never corrected.
- **M** — Mādhyandina VS 40 with svara and pada-pāṭha (vishvAsa). Another recension.
- **Mv, VD** — the mūla printed with Madhva's and Vedānta Deśika's commentaries (vishvAsa).
- **Commentaries** — Śaṅkara (Advaita Sharada units `IS_C01_*`), Vedānta Deśika
  (Rāmānuja wrote none on the Īśā), Madhva, Mahīdhara (on VS 40). Ānandagiri's ṭīkā,
  interleaved in the source, is not imported.
- **Parallels** — Advaita Sharada mūla files (Gītā, Upaniṣads, Brahmasūtra),
  Śaṅkara's BS and Kaṭha bhāṣyas, GRETIL Ṛgveda / Bṛhadāraṇyaka / Māṇḍūkya, a
  digital Muktikā (no printed source recorded; said so on the page).
- **Not used** — Swami Sharvananda's 1948 Ramakrishna Math edition (rights
  reserved) and the modern Hindi/Tamil/Marathi commentaries in the vishvAsa corpus.

## The Taittirīya (2026-11-02)

**Numbering.** vallī.anuvāka.unit: the units are the ॥N॥ divisions inside each
anuvāka (the Sāyaṇa-pāṭha's and Śaṅkara's). One page and one analysis record per
anuvāka (`analysis/1-03.json`, id `"1.3"`), the word-level fields per unit
(docs/UPANISHADS-BRIEF.md). The śānti of vallīs 2–3 (*saha nāvavatu*) is kept
apart, shown before the vallī and never numbered.

**Sources** (`import_taittiriya.py`):

- **AS (base)** — Advaita Sharada mūla of Śaṅkara's bhāṣya (`raw_etexts`,
  `…/advaita-shAradA/mUla/Taitiriya.md`); colophons stripped by the importer.
- **S** — Taittirīya Āraṇyaka 7–9, Sāyaṇa-pāṭha with svara (vishvAsa). Collated
  anuvāka by anuvāka; the only accented witness, shown unit by unit as keyed.
- **Mv** — the mūla printed with Madhva's bhāṣya (vishvAsa). It divides some
  anuvākas differently, so it is aligned by the importer and collated **vallī by
  vallī** (`scope: valli`; its variants carry `near`).
- **Commentaries** — Śaṅkara (with his introduction, `opening`), Madhva, and the
  six Viśiṣṭādvaita commentaries of the Melkote six-commentary edition, split by
  their own “[…विरचित…]” lines: Kūranārāyaṇa, Raṅgarāmānuja,
  Bhāradvāja-Rāmānuja, Rāmānanda, Gopālānanda (modern), Kauśika Govindarāja.
  Rāmānuja wrote none on this Upaniṣad. The edition prints the commentators as
  **running notes inside one another's sections, marked by sigla** that its own
  colophons identify: **‘आ.भा.’** Rāmānanda's *Ānandabhāṣya*, **‘तै. भा.’** Kauśika
  Govindarāja, **‘प्र.’** Raṅgarāmānuja's *Prakāśikā*. `import_taittiriya.route()`
  files each passage under its commentator (प्र. only at a boundary, so a citation
  ‘ब्र.वै. प्र.’ is not taken for one) and cuts at colophons («इति … कूरनारायणभाष्यम्»
  …). Until 2026-11-02 the first two were read as part of Kūranārāyaṇa's and
  Bhāradvāja's text. Anuvāka 1.12 repeats 1.1 and every commentator
  says so, so their 1.1 comments are mapped to 1.12 (`edition.json`).
- **Corrections** — fourteen slips of the base file (spacing in *saṃhitā*,
  *mīmāṃsā*, *enaṃ tato*, *puruṣavidhatām* and *nākaravam*, a doubled vowel sign, प्रमा पाहि → प्र मा भाहि, च/य, a
  dropped प, …), each confirmed by S and Mv; 109 witness differences classified.
  pāhi/bhāhi (1.4) still wants a printed Āraṇyaka: Gopālānanda and the ‘आ.भा.’
  passage read pāhi.
- **Sandhi engine** — `suvaḥ` and `dhātaḥ` were added to the r-final words in
  `scripts/devi_mahatmyam/sandhi.py` (shared; Devī Māhātmyam and Rudram re-proven),
  and *eṣaḥ* is recognised after a vowel fusion (*tenaiṣa pūrṇaḥ*).
- **Madhva's commentary** follows a mūla passage that can straddle the edition's
  anuvākas; a comment is filed under every anuvāka its passage covers.

**Phases.** PR 1 (2026-11-02, merged): engine, the whole verified text and
collation, the Śīkṣāvallī analysed (12 anuvākas) with three studies. PR 2
(2026-11-02): the Brahmānandavallī (9 anuvākas; 2.8 has five units) with three
studies (satyaṃ jñānam, the five selves, bliss), the commentary sigla and Madhva
alignment fixed, 14 corrections in all. PR 3 (2026-11-02): the Bhṛguvallī (10 anuvākas; 3.10 has six units, with the
closing sāman and its plutas), studies VII–IX (Bhṛgu's inquiry; food; the
Taittirīya as one teaching) and the concept map. **The Taittirīya is complete**:
all 31 anuvākas analysed, nine studies.
Until a vallī is listed in `edition.json` `analysed`, its pages show the verified
text, IAST and svara with “analysis in preparation”, and check.py does not
require its records.

## The Kaṭha (2026-11-02)

**Numbering.** adhyāya.vallī.mantra: 2 adhyāyas × 3 vallīs, 119 mantras (29, 25,
17; 15, 15, 18). A vallī edition whose records are single mantras: `edition.json`
`record: "mantra"`; records `analysis/A-V-NN.json` (`1-2-23.json`, id `"1.2.23"`,
one unit); pages `mantra-A-V-NN.html` with `#aA-V-N-sK` section anchors; vallīs
"1.1" … "2.3" in `analysed`. The śānti (*saha nāvavatu*), which the base prints
as 2.3.19, is kept apart.

**Sources** (`import_katha.py`): base **AS**, the Advaita Sharada mūla of
Śaṅkara's bhāṣya (its verse marks are sometimes broken across lines, so each
vallī is joined and split at its marks; ꣳ is read as ं); **G**, GRETIL (after
Olivelle 1998 — a witness only); **V**, the vishvAsa mūla; **Mv**, Madhva's mūla
(collated vallī by vallī). Commentaries: Śaṅkara, Madhva, Raṅgarāmānuja's
*Prakāśikā* (Tirupati 1948, OCR). The modern commentaries in the same folder
(Vaṅgīpura Vāsudeva; the 45th Ahobila yati) are not used. Three corrections to
the base (1.1.17 निचाय्येमां, 1.3.12 त्वग्र्यया, 2.1.8 अरण्योर्निहितो); 144 witness
differences classified. The vishvAsa checkout needs
`kAThakam/AraNyakam/kaThopaniShat/` (sparse-checkout add).

**Phases.** PR 1: the engine for mantra records, the whole verified text, the
first vallī (Naciketas and the three boons) analysed with three studies. Then one
PR per vallī.

## Rules

- **Never edit a generated page.** CI fails on stale output and on a broken internal link.
- **The text is proven, not trusted.** `letters(text)` must equal `letters(G)` apart
  from logged corrections; every letter difference of every witness must be listed
  and classified, and an entry that no longer matches fails.
- **Every padaccheda is proven** by rejoining (`scripts/devi_mahatmyam/sandhi.py`);
  unjoined hiatus must be declared, and an unneeded declaration fails.
- **No invented authority.** Every « » quotation must occur in the named
  commentary on that mantra (sound-level match, `textlib.phon`); every parallel's
  quote must occur in the passage; every Pāṇini citation is `P. a.b.c (sūtra)` and
  must match the sūtra; school positions declare their basis (commentary ·
  doctrine · inference). Verses Madhva and Deśika cite from Purāṇas are reported
  as *cited by them*.
- **Labels.** Every commentary block and every essay section carries one of
  direct · traditional · comparative · linguistic · reflection (essays may also use
  historical). Modern reflections are always labelled and never claim to be the text.
- **No medical or therapeutic claims**, no "vibration / cosmic energy / quantum"
  (the checker has the list).
- **Reading paths are presentation only.** Every section is in the HTML; the path
  decides which `<details>` are open (`data-lvl` 1/2/3). Without JS the Serious
  Student sections are open. Mantra URLs (`/upanishads/isha/mantra-NN.html`) and
  section anchors (`#m6-s10`) never change.

## Adding the next Upaniṣad

1. Import its witnesses into `upanishads/<id>/edition/witnesses/` (extend
   `import_witnesses.py`; record sources and commits), write `text.json`,
   `corrections.json`, `edition.json`, and pass `check.py` on the text alone
   (`collection.json` status `draft` until then — the build and checker skip drafts).
2. Write the model record, then the rest, to `docs/UPANISHADS-BRIEF.md`.
3. Studies, `landing.json`, `map.json`; set `edition` in `principal.json`.
4. Set status `available`; add URLs to `sitemap.xml`; `build.mjs`; `build.py all`.

## Open for Paddy / a scholar (2026-11-01)

The sources page (`/upanishads/isha/sources.html#open`) lists everything; in short:

- **Scholarly review of all prose** — translations, beginner explanations,
  commentary, studies. Every record is `machine-verified`, none `reviewed`.
- **Textual verification required** (a printed Kāṇva Saṃhitā / Madhva bhāṣya):
  K's अविद्याया in 10, K's shortened 16 and रूपे, Madhva's missing च in 14.
- **Madhva's digital commentary is abridged** at 9–11, 12–14, 15 and 16 (marked ‘…’
  in the source); his readings there are partly unknown and marked so.
- 10 interpretation flags, 5 uncertainties (see the sources page).
- Svara is shown only from the keyed Kāṇva witness; it should be proof-read
  against a printed Saṃhitā before it is presented as authoritative.
